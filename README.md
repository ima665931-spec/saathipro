# SaathiPro

India's #1 Professional Social & Lifestyle Support Platform

## What is this?

A modern Next.js landing page inspired by professional companionship / social support platforms. Features:

- Beautiful responsive landing page
- Services (Movie Partner, Elder Care, Hangout, Clubbing, etc.)
- Success stories & earnings section
- FAQ accordion
- Mobile-friendly design

## Tech Stack

- **Next.js 16** (App Router)
- **TypeScript**
- **Tailwind CSS v4**
- React 19

## How to run

```bash
# Install dependencies
npm install

# Start development server
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) in your browser.

## Project Structure

```
src/
  app/
    page.tsx      # Main landing page
    layout.tsx    # Root layout
    globals.css   # Global styles
```

## Name

**SaathiPro** = Saathi (companion in Hindi) + Pro (professional)
